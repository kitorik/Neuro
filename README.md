# Neuro — Инкрементал: Бег (JustMc Creative+)

Модуль для мини-игры Creative+ на сервере JustMc. Импортируй JSON из файла `Code`.

## Как играть
- Игра запускается при входе игрока в мир (`player_join`); карта строится при запуске мира (`world_start`) на точке спавна.
- Беги по красной дорожке длиной 200 блоков — каждый пробежанный блок приносит монеты.
- Через каждые 25 блоков жёлтая отметка: чем дальше от старта, тем выше бонус зоны (до x3).

## NPC в хабе (ПКМ)
| NPC | Действие |
|---|---|
| Скорость | +1 уровень скорости бега (макс. 20) |
| Множитель | +0.5 к множителю монет |
| Перерождение | сброс монет и улучшений, +1 к постоянному множителю дохода |
| Статистика | монеты, дистанция, уровни и цены следующих улучшений |

## Карта
- Хаб с колоннами из кварца и фонарями, полом из андезита с тёмной окантовкой, стартовой площадкой и голограммой с правилами; четыре NPC.
- Беговая дорожка 200 блоков: красное покрытие, белая разметка, красно-белые бордюры, жёлтые отметки каждые 25 м с голограммами.
- Арки «СТАРТ» и «ФИНИШ», клетчатая финишная линия.
- Бортики: каменное основание и голубое стекло.
- Трибуна вдоль дорожки, фонарные столбы, берёзы вдоль трассы.
