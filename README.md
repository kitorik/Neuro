# Neuro — Инкрементал: Бег (JustMc Creative+)

Модуль для мини-игры Creative+ на сервере JustMc. Импортируй JSON из файла `Code`.

## Как играть
- Игра запускается при входе игрока в мир (`player_join`); карта строится при запуске мира (`world_start`) на точке спавна.
- Беги по красной дорожке длиной 200 блоков — каждый пробежанный блок приносит монеты.
- Через каждые 25 блоков жёлтая отметка: чем дальше от старта, тем выше бонус зоны (до x3).

## Команды в чате
| Команда | Действие |
|---|---|
| `!shop` / `!магазин` | цены улучшений |
| `!speed` / `!скорость` | +1 уровень скорости (макс. 20) |
| `!mult` / `!множитель` | +0.5 к множителю монет |
| `!rebirth` / `!перерождение` | сброс монет и улучшений, +1 к постоянному множителю дохода |
| `!stats` / `!стата` | статистика |
| `!spawn` / `!старт` | телепорт на старт |

## Карта
Хаб 9×19 с табличкой-голограммой, красная беговая дорожка 7 блоков шириной с белой разметкой, стеклянные бортики, отметки дистанции с голограммами.
